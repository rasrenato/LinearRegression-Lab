# Laboratório de Regressão Linear Interativa / Interactive Linear Regression Lab

Este repositório contém os exercícios do laboratório opcional do curso **"Aprendizado de Máquina Supervisionado: Regressão e Classificação"**. O laboratório explora a implementação de regressão linear univariada e a criação de visualizações interativas. This repository contains the exercises from the optional lab of the **"Supervised Machine Learning: Regression and Classification"** course. The lab explores the implementation of univariate linear regression and the creation of interactive visualizations.

## Conteúdo / Content
- `C1_W1_Lab02_Model_Representation_Soln.ipynb`: Notebook com os códigos do laboratório. / Notebook containing the lab's code.
- `C1_W1_Lab03_Cost_function_Soln.ipynb`: Notebook para visualização da superfície convexa da função de custo (formato "soup bowl"). / Notebook for visualizing the convex cost function surface (soup bowl format).
- `README.md`: Informações sobre o projeto. / Project information.
- `requirements.txt` (opcional): Lista de dependências para o projeto. / (Optional) List of project dependencies.

## Como usar / How to Use
1. Clone este repositório: execute no terminal `git clone <URL_DO_REPOSITORIO>` / Clone this repository: run `git clone <REPOSITORY_URL>` in your terminal.
2. Instale as dependências: execute `pip install -r requirements.txt` / Install dependencies by running `pip install -r requirements.txt`.
3. Abra os notebooks no Jupyter: inicie o Jupyter Notebook ou o JupyterLab e abra os arquivos `.ipynb`. / Open the notebooks in Jupyter: launch Jupyter Notebook or JupyterLab and open the `.ipynb` files.
